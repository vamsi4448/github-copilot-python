# Refactoring Legacy Code with GitHub Copilot

A Python Flask Sudoku application refactored and enhanced using GitHub Copilot.

## Project Features

- Easy, Medium, and Hard difficulty levels
- Sudoku puzzle generation with a unique solution
- Invalid move detection
- Hint functionality
- Puzzle checking
- Timer
- Top 10 leaderboard using browser localStorage
- Light and dark modes
- Responsive Sudoku interface
- Automated pytest tests
